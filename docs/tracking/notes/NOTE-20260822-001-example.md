# NOTE Example: Apple API Hallucination Risk

**ID**: NOTE-20260822-001-api-hallucination-example  
**Status**: open  
**Priority**: P0-critical  
**Created**: 2026-08-22  
**Updated**: 2026-08-22  
**Assignee**: human  

## Observation

AI agents (including Qwen3-Code:30B) will confidently hallucinate Apple Foundation Models API names and usage patterns if not given exact documentation.

## Evidence

During Phase 3 planning, AI suggested:

```swift
// HALLUCINATED - This API doesn't exist!
import AppleIntelligence
let model = AIModel.foundation()
let result = model.generate(prompt: "Hello")
```

When the actual API (as of macOS 15.1) is likely:

```swift
import IntelligenceFramework  // Or similar
// Actual API TBD - requires research
```

## Impact

**CRITICAL**: This blocks Phase 3 completely.

If AI proceeds with hallucinated APIs:
- Code won't compile
- Wasted implementation effort
- False confidence in "completion"
- Debugging nightmare

## Root Cause

AI training data doesn't include:
- macOS 15+ private/beta APIs
- Unreleased framework names
- Exact method signatures
- Availability annotations

AI fills gaps with "reasonable" guesses based on patterns from other frameworks.

## Mitigation Strategy

**REQUIRED before Phase 3 starts:**

1. **Human completes GSD Task 3.0.1**:
   - Research actual Apple Foundation Models API
   - Extract from:
     - Apple Developer docs
     - WWDC sessions
     - Xcode headers
     - Sample code
   - Create working code examples
   
2. **Document in `docs/ai_context/`**:
   - Exact import statements
   - Actual class/struct names
   - Real method signatures
   - Availability guards
   - 3-5 working examples

3. **AI reads context before task**:
   - AI MUST read `docs/ai_context/foundation_models_api.md` before task 3.1.1
   - Use examples as authoritative source
   - Flag any API usage not in docs

## Decision

**Phase 3 is BLOCKED until human completes task 3.0.1**

AI MUST NOT:
- Proceed with Phase 3 without API docs
- Guess API names
- Use patterns from other frameworks
- Assume anything about the API

AI MUST:
- Wait for `docs/ai_context/foundation_models_api.md` to exist
- Use only documented APIs
- Flag any uncertainty
- Ask for human research if docs incomplete

## Verification

Before unblocking Phase 3:

```bash
# Check context exists
test -f docs/ai_context/foundation_models_api.md || exit 1
test -f docs/ai_context/foundation_models_examples.swift || exit 1

# Check it has real content
grep -q "import" docs/ai_context/foundation_models_api.md || exit 1
grep -c "func" docs/ai_context/foundation_models_examples.swift | \
  awk '$1 >= 3 || exit 1'

# Try to compile examples (if on macOS 15+)
if [ $(sw_vers -productVersion | cut -d. -f1) -ge 15 ]; then
  swift docs/ai_context/foundation_models_examples.swift || exit 1
fi
```
